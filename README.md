# Gunshot and Siren Detection System

A real-time audio classification system that detects gunshots and emergency
vehicle sirens using a two-stage CNN pipeline trained on mel spectrograms.

## Results

| Stage | Task | Test Accuracy |
|---|---|---|
| Stage 1 | Gunshot / Siren / Background | 96.2% |
| Stage 2 | Police / Ambulance / Firetruck / Unknown | 91.0% |

Gunshot recall: 99% - the system almost never misses a real gunshot event.

## Project Structure

```
DL/
  src/
    config.py          <- all hyperparameters in one place
    prepare_data.py    <- organises raw datasets into class folders
    preprocess.py      <- converts audio to mel spectrogram .npy files
    augment.py         <- audio augmentation helpers
    dataset.py         <- PyTorch Dataset and DataLoader
    model.py           <- 3-block CNN architecture (used for both stages)
    train.py           <- trains Stage 1 and Stage 2 models
    evaluate.py        <- confusion matrix and per-class metrics
    predict.py         <- run inference on a single audio file
    live_detect.py     <- real-time microphone detection with alerts
  data/
    raw/
      datasets/        <- place downloaded datasets here (not in git)
      stage1/          <- generated by prepare_data.py
      stage2/          <- generated by prepare_data.py
    processed/         <- generated by preprocess.py (not in git)
  checkpoints/         <- saved model weights (not in git)
  logs/                <- detection logs from live_detect.py (not in git)
  Dockerfile
  docker-compose.yml
  requirements.txt
```

## Setup

### Requirements

- Docker Desktop (for training and evaluation)
- Python 3.11+ with conda or venv (for live detection only)
- Windows or macOS

### Install Docker Desktop

Download from https://www.docker.com/products/docker-desktop and install.
On Windows, choose WSL 2 when prompted.

### Build the Docker image

```bash
docker compose build
```

---

## Training Pipeline (run inside Docker)

### Step 1 - Organise datasets

```bash
docker compose run app python src/prepare_data.py
```

Creates `data/raw/stage1/` and `data/raw/stage2/` with the correct class structure.

### Step 2 - Compute mel spectrograms

```bash
docker compose run app python src/preprocess.py
```

Converts all audio files to mel spectrogram `.npy` files. Takes 30-40 minutes.

### Step 3 - Train both stages

```bash
docker compose run app python src/train.py
```

Trains Stage 1 then Stage 2 automatically. Takes 2-4 hours on CPU.
To train a single stage:

```bash
docker compose run app python src/train.py --stage 1
docker compose run app python src/train.py --stage 2
```

### Step 4 - Evaluate

```bash
docker compose run app python src/evaluate.py
```

Prints per-class precision, recall, F1 and saves confusion matrix PNGs to `checkpoints/`.

## Inference on a Single File (run inside Docker)

```bash
docker compose run app python src/predict.py --file path/to/audio.wav
docker compose run app python src/predict.py --file path/to/audio.wav --verbose
```

The file must be inside the project folder so Docker can access it.

Example output:
```
File   : gunshot_test.wav
Result : gunshot
Confidence : 99.91%
```

## Live Detection (run outside Docker)

Live detection runs directly on your machine since it needs microphone access.

### Install dependencies

```bash
pip install torch torchaudio librosa sounddevice numpy scikit-learn matplotlib pandas soundfile tqdm
```

### Connect your microphone

Any of the following work:
- Built-in laptop microphone
- Wired headset (3.5mm or USB)
- Phone microphone via WO Mic (https://wolicheng.com/womic/)

### List available audio devices

```bash
python src/live_detect.py --list-devices
```

Note the index number of your microphone.

### Start live detection

```bash
python src/live_detect.py --device 2
```

Replace `2` with your microphone index. Omit `--device` to use the system default.

### Options

```bash
python src/live_detect.py --device 2 --threshold 0.90 --interval 0.5
```

- `--threshold` - minimum confidence to trigger an alert (default: 0.85)
- `--interval` - seconds between inference runs (default: 0.5)

### Alert format

When a detection occurs the terminal displays:

```
!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
  WARNING: GUNSHOT DETECTED at 11:19:20 PM
  Confidence: 99.91%
!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!
```

### Detection logs

Every session is automatically logged to `logs/detections_YYYYMMDD_HHMMSS.txt`:

```
[2026-05-13 23:19:20] WARNING: GUNSHOT DETECTED at 11:19:20 PM | confidence: 99.91%
[2026-05-13 23:19:25] All clear at 11:19:25 PM
```

Press Ctrl+C to stop. The log file is saved automatically.

## Using WO Mic (phone as microphone via USB)

1. Install WO Mic on your Android phone from the Play Store
2. Install the WO Mic PC client and driver from https://wolicheng.com/womic/
3. Enable USB debugging on your phone (Settings -> Developer options)
4. Set USB mode to No data transfer
5. Open WO Mic on your phone, select USB, press the Play button
6. Open WO Mic client on PC, select USB, press Connect
7. Run `python src/live_detect.py --list-devices` and find "WO Mic Device"
8. Run `python src/live_detect.py --device <number>`

## Architecture

Both stages use the same 3-block CNN:

```
Input: mel spectrogram (1 x 128 x 173)
Block 1: Conv2D(32) -> BatchNorm -> ReLU -> MaxPool -> Dropout
Block 2: Conv2D(64) -> BatchNorm -> ReLU -> MaxPool -> Dropout
Block 3: Conv2D(128) -> BatchNorm -> ReLU -> MaxPool -> Dropout
GlobalAveragePooling
Dense(256) -> ReLU -> Dropout
Dense(num_classes) -> Softmax
```

Stage 1 outputs: gunshot / siren / background
Stage 2 outputs: police / ambulance / firetruck / unknown

Stage 2 only runs when Stage 1 predicts siren. If Stage 2 confidence is below
the threshold (default 0.60), the result is returned as siren (unknown).
